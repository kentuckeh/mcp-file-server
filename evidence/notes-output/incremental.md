# Incremental Model

> Reviewed in Session 2. See INDEX.md for the full list.

## Definition
- A software development model where the product is designed, implemented, and tested in successive, modular increments with each release adding functional capability.

## When to Use
- Best suited when core system requirements are defined upfront but secondary features can evolve, or when early market entry is critical.

## Pros
- Delivers functional software early and frequently, providing immediate operational value to users.
- Easier to test, debug, and manage technical risk through smaller, modular stages.

## Cons
- Demands strong architectural foresight and clean interfaces to avoid integration friction between increments.
- Total development cost may exceed initial estimates if increment scopes expand iteratively.
