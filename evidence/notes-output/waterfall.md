# Waterfall Model

> Reviewed in Session 2. See INDEX.md for the full list.

## Definition
- A linear-sequential software development lifecycle model where each development phase must be completed before the subsequent phase begins.

## When to Use
- Best suited for projects with well-defined, stable requirements, mature technology, and minimal likelihood of mid-project changes.

## Pros
- Simple, structured, and easy to understand and manage with clear milestones and deliverables.
- High level of documentation discipline and predictable scheduling for fixed-scope projects.

## Cons
- Inflexible to requirement changes once development is underway.
- Working software is produced late in the development cycle, increasing late-stage integration and delivery risk.
